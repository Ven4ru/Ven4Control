# История изменений

## Следующая версия

- Добавлена панель управления выбранным устройством.
- Добавлены показатели CPU, памяти, диска и времени работы.
- Добавлены статусы Tailscale и WireGuard.
- Добавлены список и перезапуск сервисов OpenWrt/Linux.
- Добавлен просмотр системных логов, Tailscale, AdGuard и Xray.
- Добавлены обновление пакетов, перезагрузка и резервное копирование конфигов.
- Добавлены проверка и установка обновлений OpenWrt через `owut` или `auc`.

## 1.0.0 — 2026-06-29

Первый закрытый MVP.

- Добавлен список OpenWrt-роутеров и Ubuntu-серверов.
- Реализована проверка доступности SSH.
- Добавлено подключение по паролю и SSH-ключу.
- Реализована установка публичного ключа с backup `authorized_keys`.
- Добавлена проверка SSH fingerprint.
- Секреты вынесены в Windows Credential Manager.
- Добавлен импорт устройств Tailscale.
- Реализована общая панель действий и запуск Windows Terminal.
- Исправлены права приватного ключа и жизненный цикл фоновых проверок.
- Исправлен повторный запуск после защиты ACL приватного SSH-ключа.
